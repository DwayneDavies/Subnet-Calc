Subnet Calc

About

This is a simple subnet calculator written in JavaScript. I created this mostly as a hobby project and as part of my developer portfolio.

I chose not to use any existing code that might exist to help perform this task. It was more fun to write the code to do all this math for me, especially as it helped me verify that I have some grasp of subnetting concepts.

You can use this however you like and not just for helping you figure out subnetting. You may steal some of my code if you find it useful.

You will probably find that most things are done in a simple way, without anything tricky. Not that performance is likely to be an issue, as there are not a lot of complicated operations here and there is no server-side data. Everything is calculated by your browser.

Enter an IPv4 address and choose a CIDR prefix. Hover over, or tab to, any result label to find out what the term means.

Results

Network addressThe first address in the subnet. Every host bit is 0.
Subnet maskMarks which bits of an address identify the network (1s) and which identify the host (0s).
Broadcast addressThe last address in the subnet, used to reach every host on it at once. Not used on /31 and /32 subnets.
Wildcard maskThe subnet mask flipped. Router access lists use it, and a 1 means "this bit can be anything".
Subnets in this blockHow many subnets of this size fit in the block that shares your address's leading octets. For example, a /20 gives 16, because 16 of them fit in each /16.
Addresses per subnetEvery address in the subnet, including the network and broadcast addresses. This is 2 to the power of the host bits.
Usable hostsThe addresses you can give to devices: addresses minus 2. A /31 has 2 usable hosts and a /32 has 1.
First hostThe lowest address you can assign to a device.
Last hostThe highest address you can assign to a device.
Subnets in this block Showing the subnets that share the first octets of your address (for example 192.168.x.0 for a /20).
